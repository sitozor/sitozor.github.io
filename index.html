Что проверяем

Самые частые причины, по которым небольшие сайты теряют клиентов, попадают в спам или оказываются взломаны.

SSL-сертификат

Действует ли сертификат и когда истекает. Истёкший сертификат — это предупреждение «сайт небезопасен» у каждого посетителя.

Защита почты

Записи SPF и DMARC. Без них мошенники могут рассылать письма от имени вашего домена, а ваши письма чаще попадают в спам.

Настройки безопасности

Защитные заголовки, cookies, перенаправления — то, что закрывает сайт от распространённых атак через браузер.

WordPress и плагины

Версия WordPress, список плагинов и тем, сверка версий с базой известных уязвимостей.

Утечки ключей

Ключи доступа к платным сервисам, случайно оставленные в коде, который видят посетители.

Отчёт, понятный не только программистам

Кроме технических отчётов (HTML, JSON, SARIF) инструмент создаёт отдельный отчёт для владельца сайта.

  • Светофор: всё хорошо, есть замечания или нужны срочные действия
  • Для каждой проблемы — что это значит и что сделать
  • Что изменилось с прошлой проверки; исправления подтверждаются повторной проверкой
  • Ваш логотип и название — удобно для веб-студий
  • Один HTML-файл, сохраняется в PDF через печать

Установка

Инструмент Сайтозора распространяется на GitHub под названием web-audit-pro. Нужен Python 3.11 или новее. Проверяйте только свои сайты или сайты, на проверку которых у вас есть разрешение.

git clone https://github.com/HackToolWork/web-audit-pro.git
cd web-audit-pro
sudo ./install.sh
git clone https://github.com/HackToolWork/web-audit-pro.git
cd web-audit-pro
docker build -t web-audit-pro:local .
mkdir -p reports
docker run --rm -u "$(id -u):$(id -g)" -v "$PWD/reports:/app/reports" \
  web-audit-pro:local https://ваш-сайт.ru --yes-i-am-authorized --lang ru
git clone https://github.com/HackToolWork/web-audit-pro.git
cd web-audit-pro
python -m venv .venv
.venv\Scripts\activate        # macOS: source .venv/bin/activate
python -m pip install .

Проверка сайта

web-audit https://ваш-сайт.ru --yes-i-am-authorized --lang ru --company "Моя студия"

Отчёты появятся в папке reports/; отчёт для владельца — файл owner-report-*.html. Подробности — в документации.

Частые вопросы

Это действительно бесплатно?

Да. Инструмент распространяется с открытым кодом под лицензией Apache-2.0 — его можно использовать, в том числе в коммерческих целях. Платным будет только готовый сервис мониторинга, где не нужно ничего устанавливать.

Это не взлом? Сайту ничего не будет?

Нет. Инструмент делает только обычные запросы — такие же, как браузер при посещении сайта, — с ограничением скорости. Он не подбирает пароли, не отправляет вредоносные данные и не нагружает сервер. Проверяйте только свои сайты или сайты, на проверку которых у вас есть разрешение.

Нужно ли быть программистом?

Нужно уметь установить программу и запустить одну команду в терминале — инструкция выше. Если это неудобно, подождите запуска мониторинга: там будет достаточно ввести адрес сайта.

Откуда данные об уязвимостях WordPress?

Из базы Wordfence Intelligence. Её можно бесплатно скачать один раз командой web-audit --update-wp-db (нужен бесплатный API-ключ Wordfence) — дальше проверки работают без интернета.

Гарантирует ли отчёт, что сайт не взломают?

Нет, и мы честно об этом пишем. Автоматическая проверка находит самые распространённые проблемы, но не заменяет полноценный аудит безопасности.
